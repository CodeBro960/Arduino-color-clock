# Arduino-color-clock

## Project Overview
I am building a digital clock using an Arduino Uno,
DS3231 RTC, and ILI9341 TFT display.

### Hardware
- Arduino Uno R3
- DS3231 RTC
- ILI9341 TFT display
- Push buttons
