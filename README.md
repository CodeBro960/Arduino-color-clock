# Arduino Color Clock

## Project Overview

I am building a digital clock using an Arduino Uno, a DS3231
real-time clock module, and an ILI9341 TFT display.

The clock will display:

- Current time in 12-hour format
- Day of the week

My custom feature will allow the user to independently
change the color of the time and day of the week.

## Project Goals

- Learn Arduino fundamentals
- Learn how to use an RTC
- Learn how to control a TFT display
- Learn how to use buttons as user input
- Create a settings menu
- Implement customizable colors
- Save user settings

## Hardware

- Arduino Uno R3
- DS3231 RTC
- ILI9341 2.4" TFT display
- Push buttons
- Breadboard
- Jumper wires
